How this preview works: the page reads the dashboard JSON directly. Titles, descriptions, the gridPos layout, field config, overrides, thresholds, the -- Dashboard -- data-source wiring and the data links all come from it. Panel SQL is shown but never executed. Each panel's query is mirrored by a small JavaScript function over a seeded synthetic agent_events table that your browser generates, so the page makes no network requests. Agents, users, model identifiers and errors are invented. Series colours are Grafana palette families re-stepped for colour-vision separation on the dark panel surface, and each event type keeps its colour across panels and filters.
