## Never-emit (telemetry / tool results)

`concept_version_id`, bundle-relative paths, principal, query text, named parameter values, destination table ids as raw names. Agent-facing payloads carry `context_ref` (opaque) plus RFC-allowed receipts. UI may show authored paths in the **bundle inspector** (that's source, not telemetry).
