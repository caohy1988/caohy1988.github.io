What is real here, and what is not
  • Real, live GCP: dataset test-project-0728-467323.okf_rfc_demo.agent_events; ADK agent okf_rfc_consume_agent on gemini-3.8-flash (Vertex global); session 04fa3d56-f2f1-413e-8c2b-ec116835af84; Dataplex entry okf-derived-germany in group okf-rfc-demo. The 14 rows in live/agent_events.json are a committed export of that run.
  • Real, authored fixture: Phase 0 golden identities and PROFILE.md hashing (JS + Python). The derived bundle in beat 2 is computed in-browser from the labelled synthetic adapter input.
  • Synthetic, labelled: the Germany fixture trace used as adapter input (never written to a table). In-browser Catalog/BQ projection tables in beat 3 are derived views, not extra DML.
  • Honest by construction: this live run minted no receipt. Nothing is ATTESTED. The model’s “verified” wording overstates. The Phase 0 UNVERIFIABLE specimen remains the only receipt, a fixture.
  • Never emitted on agent-facing payloads: concept_version_id, bundle paths, principal, SQL / query text, parameter values, raw destination table names.
Run it locally

Static files, no build. From the repo root: python3 -m http.server 8000 then open http://localhost:8000/rfc/demo/. Check the live snapshot with python3 rfc/demo/tools/check_live_trace.py. Derived vectors: python3 rfc/demo/tools/derived_vectors.py. See README.md.
