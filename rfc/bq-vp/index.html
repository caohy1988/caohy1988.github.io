Illustrative scenario · invented company, people & numbers

The board pack says 118%.
Retention is 96%.

8:55 a.m. Maya Chen, VP of Finance at subscription software company Alder, has five minutes before the board decides on a $4 million plan to expand sales to existing customers. Her agent calls 118% retention “verified.” Revenue from those customers actually fell 4%.

An analyst catches it. Maya pulls the slide. The agent cited Finance’s definition but reused a total-ARR query. New business made a shrinking customer base look like growth.

Why BigQuery · proposed runtime · RFC, not built

Make the agent’s context replayable.

Similarity search finds candidate passages; it doesn’t fix which linked context the agent actually used. Maya needs a repeatable walk from the retention definition to its cohort rule and approved computation. Walk the same graph twice and the agent gets the same definition, cohort rule and declared computation — no room to substitute a total-ARR query.

Knowledge Catalog

Discover and govern.

Find Finance’s approved retention concept and its owner. Discovering an entry is not a deterministic traversal of its linked OKF context.

Open Knowledge Format (OKF)

Author the graph.

Author definitions, relationships, computation declarations and versions. OKF supplies the authored graph, not a query engine.

BigQuery

Retrieve deterministically.

Project the graph into BigQuery. Pin a publication and retrieve linked context with explicit SQL or bounded graph walks.

Same fixed inputs → same context and result shape. Fix the query, parameters, fact versions, access scope and ordering. A retrieval receipt records the query, pins and selected context.

Then compute retention with a separate job ↔ context ↔ result receipt; trace the agent and execution identity under IAM.

The knowledge graph can be the first workload. Starting with an empty BigQuery project, land the OKF projection and version the facts that retrieval needs there. No revenue warehouse is required to start retrieving context.

BigQuery turns the OKF graph into replayable context for agents.

One ask of the BigQuery VP

Sponsor one retention pilot with a Finance owner.

Pilot Finance’s graph and one quarter of cohort data. Repeat the pinned retrieval and compare context; then compute retention. Withhold execution evidence: the number must remain unproven.
