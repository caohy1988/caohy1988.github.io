Tech Talk

Everyone Is a TL Now: Working With Teams of AI Agents

How I run Claude Code, Codex, and Kimi Code as parallel agent teams for daily engineering and learning — and why the shape of orgs, and the definition of work itself, is about to shift.

Speaker Haiyuan Cao Date TBD Format Talk + Q&A
A note on scope: this talk is given in a personal capacity. Nothing in the talk or the slides covers, references, or draws on my work at Google. All examples come from personal projects, open-source tools, and publicly available information.

Abstract

AI coding agents stopped being autocomplete a while ago. Run several of them at once — each with its own strengths, each holding hundreds of thousands of tokens of context — and your job quietly changes: you stop writing most of the code and start specifying, delegating, reviewing, and arbitrating, the way a tech lead runs a team.

This talk is a field report from working that way every day. I'll show how I combine Claude Code, Codex, and Kimi Code as complementary agent teams; how I use their huge context windows to learn new codebases, papers, and fast-moving trends far faster than I could alone; and where I think this leads: a world where every engineer is a TL — and increasingly an M2 — of agent teams, where the number of agent teams you can effectively manage becomes a real competitive edge, and where org shape and the very definition of "work" have to be redrawn.

What we'll cover

Part 1 · Practice

Running agent teams day to day

My working setup with Claude Code, Codex, and Kimi Code: how work gets split across agents, how agents review each other's output, and which tasks each one is actually good at. Concrete workflows, not demos.

Part 2 · Learning

Learning at agent speed

Using massive context windows as a learning instrument: dropping whole codebases, papers, and docs into an agent and interrogating them. How this changes learning efficiency and how I stay current with a field that moves weekly.

Part 3 · Future

Everyone is a TL and an M2

What happens to collaboration when management span over agents — not headcount — becomes the edge. How org shapes flatten and reform, why "writing code" stops being the unit of work, and what to practice now to be ready.
