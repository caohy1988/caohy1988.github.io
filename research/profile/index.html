Profile

Haiyuan Cao

Building agent trace and context layers at Google.

Haiyuan works at Google on agent observability: recording what AI agents do as traces in BigQuery, and giving teams the tools to analyze and evaluate it. He builds in the open, with a team of AI agents working under his direction.

Areas of technical leadership

Agent observability on BigQuery

He works at Google on BigQuery Agent Analytics. Agent frameworks write their events to one agent_events table in BigQuery, and an open-source SDK reads that table for trace reconstruction, evaluation and dashboards.

Open-source stewardship

The work ships in public repositories. He is one of two listed maintainers of BQ-OTEL-Exporter and prepared its v0.1.0 release. On the SDK, release pull requests and nightly audits for security, documentation drift and dead code come from his accounts.

ADK documentation and Go package

He contributes to Google’s Agent Development Kit: documentation in adk-docs, including the Go plugin documentation for BigQuery Agent Analytics, and the agentanalytics package in adk-go.

Engineering with an agent team

He runs a multi-agent coding and research team, and publishes its playbook and a lab of curated tips and methods on this site.

Selected projects

  • BigQuery Agent Analytics SDK

    Python

    An open-source SDK for analyzing, evaluating and curating agent traces stored in BigQuery: trace reconstruction, evaluation metrics and graders, dashboards, and a context graph of agent decisions.

    321 pull requests opened and 307 merged. Release pull requests for versions 0.5.4, 0.6.0, 0.6.1 and 0.6.2 merged between 2026-09-29 and 2026-11-05.

  • BigQuery Agent Analytics Plugins

    TypeScript

    Plugins that stream coding-agent sessions to BigQuery in the same agent_events schema, so coding-agent activity can be analyzed next to ADK agents.

    10 pull requests opened and 7 merged since the repository was created on 2026-11-01.

  • BQ-OTEL-Exporter

    Go

    An OpenTelemetry Collector exporter that writes OTLP traces, logs and metrics to BigQuery through the Storage Write API, with a documented schema and read-time deduplication.

    One of two listed maintainers. 31 pull requests opened, all merged. Prepared the v0.1.0 release.

  • Agent Development Kit (ADK)

    Documentation and Go

    Documentation in google/adk-docs, including the Go plugin documentation for BigQuery Agent Analytics, and work on the agentanalytics package in google/adk-go.

    27 pull requests merged to adk-docs and 18 to adk-go, from the Google work account.

  • BigQuery Agent Analytics skill

    Agent skill

    A prompt-only skill, with no server to run, that gives AI coding assistants ready-made queries and an analysis method for BigQuery Agent Analytics data.

    Ships with 5 base CTEs, 8 ready-to-run analytics queries and 11 diagnostic patterns.

  • dcx

    Rust

    An agent-native command-line tool for BigQuery, Spanner, AlloyDB, Cloud SQL and Looker, with structured JSON output and typed errors.

    Its analytics commands wrap the BigQuery Agent Analytics SDK.

Counts are pull requests opened from his two GitHub accounts, as of 2026-11-10. Many were produced with an AI agent team under his direction.
