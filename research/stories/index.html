Product progress (checked 2026-11-18)

A short check of the public releases. The stories follow below. Our five checks since the Nov 15 update found no new stories. This refresh updates the product progress.

The latest SDK release is v0.7.0 from Nov 13. PyPI also shows 0.7.0. SDK v0.6.2 shipped on Nov 5, before v0.7.0 on Nov 13. See the SDK releases and the PyPI page (checked 2026-11-18).

SDK v0.7.0 and v0.6.2

  • v0.7.0 (Nov 13): Evaluation reports now list scores separately for sessions that passed and sessions that failed (#581).
  • v0.7.0: create_all_views() and bq-agent-sdk views create-all now deploy four more ADK 2.0 cross-event views: agent_transfer_chains, branch_fanout, scope_cardinality, and workflow_invocations (#587).
  • v0.7.0: Client.insights() now calls the configured Gemini API model instead of a fixed gemini-2.5-flash (#580). The SDK can now follow SKOS links between concepts imported with gm import-owl (#579).
  • v0.6.2 (Nov 5): a security audit closes SQL injection paths through configuration values (#539–#542). Drift and deep analysis check the events table, project ID, and dataset ID, and the client checks its project and dataset IDs. Invalid values in those fields raise ValueError before a query is sent. A wildcard events table for drift and deep analysis is now refused.
  • v0.6.2: outside the Python package, the bqaa-tracing plugin marketplace moved to GoogleCloudPlatform/BigQuery-Agent-Analytics-Plugins (#573) with the add-on for coding agents (#538). Dashboards were consolidated under dashboards/ (#548), and a Power BI port (#567) and a Grafana efficiency-trial dashboard (#572) landed.

On main since v0.7.0 — unreleased

Only a CI publishing change (#590, Nov 16) is on main since v0.7.0, and it does not change the library (checked 2026-11-18).

ADK plugin updates

  • ADK Python v2.14.1 (Nov 12) only turns off FastAPI's native tracing on Agent Engine, with no BigQuery plugin change (checked 2026-11-18).
  • ADK Python v2.14.0 (Nov 4) records workflow node observations in the BigQuery plugin. A new flag can write content_formatter error details to BigQuery. Stream-level non-retryable write errors are labeled non_retryable, and errors are clearer when write_mode is BLOCKED. Built-in BigQuery skills are now loadable via get_bigquery_skill (checked 2026-11-18).
  • ADK Python v2.13.0 (Oct 22) now labels write-time 403 and 404 drops in the BigQuery plugin (checked 2026-11-18).
  • ADK Python v2.12.0 (Oct 13) added schema callbacks for the BigQuery logger, richer start metadata, and code-execution formatting and custom metadata capture in BQAA telemetry (checked 2026-11-18).

Docs

The docs page says BigQuery agent analytics is supported in ADK and LangGraph, with no Preview label on the page. Logging uses the ADK plugin or the LangGraph and LangChain BigQueryCallbackHandler, from the langchain-google-community[bigquery] package. See BigQuery Agent Analytics docs (checked 2026-11-18).

The latest BQAA entry in the release notes is April 15, 2026, when BigQuery agent analytics became generally available (GA) in ADK, with no newer BQAA entry since then. See BigQuery release notes (checked 2026-11-18).
