Product progress (checked 2026-10-28)

A short check of the public releases. The stories follow below.

The latest SDK release is still v0.6.1 from Oct 20. PyPI also shows 0.6.1. There is no newer release yet. See the SDK releases and the PyPI page (checked 2026-10-28).

On main since v0.6.1 — unreleased (not in a wheel yet)

These changes are on commits on main only. They are not in a release yet (checked 2026-10-28).

  • A coding-agent tracing plugin was added to the tracing marketplace, with its own checks (#538, Oct 23).
  • Plugin hooks now honor the tracing on/off setting, and setup reports dry-run mode (#543, Oct 27).
  • Coding-agent tracing hooks no longer crash on bad numeric settings (#549, Oct 27).
  • Credential hiding in the hook sanitizer is stronger (#546, Oct 26).
  • Dashboard folders were moved into one dashboards/ folder (#547, Oct 26).
  • A security pass added ID checks and safer handling for model endpoints and drift tables (#539–#541, Oct 21–22).
  • Small cleanups landed for CI, doc links, and unused code (#552, #544, #551, #545).

ADK plugin updates

  • ADK Python v2.12.0 (Oct 13) added schema callbacks for the BigQuery logger, richer start metadata, and code-execution formatting and custom metadata capture in BQAA telemetry (checked 2026-10-28).
  • ADK Python v2.13.0 (Oct 22) now labels write-time 403 and 404 drops in the BigQuery plugin (checked 2026-10-28).

Docs

Docs list support for ADK and LangGraph (Preview). See BigQuery Agent Analytics docs (checked 2026-10-28).
