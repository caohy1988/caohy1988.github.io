1. NEW rank: RSIAgent — training-free three-role harness builds frozen, hash-checked exploration memory that lifts open-model computer-use past reported frontier scores; the harness, not the model, does most of the lifting

RSIAgent: Autonomous Exploration for Recursive Self-improvement in New Environments, Sibo Zhu, Shicheng Fan, Xinyue Wang, Wenyi Wu, Kun Zhou, Biwei Huang (Aether AI / UCSD / UIC). v1 2026-09-14, Monday cycle; no v2. Full text read including Appendices A–E (prompts P1–P7, Tables A1–A8). (PDF)

A training-free multi-agent harness: a curriculum agent proposes practice tasks, an actor executes with an evolvable memory, and an independent verifier (blind to actor reasoning, grounded in environment feedback) gates outcomes — broad parallel exploration (BRS) then deep sequential stress-testing (DRS), with the resulting memory frozen (file-tree hash recorded, writeback disabled) and injected into prompts at eval time. Verified findings:

  • Headline scores, exactly (Table 1): OSWorld-2.0 (82-task offline subset) partial 78.98 vs GPT-6 Astra 72.60 (+6.38) and Claude Opus 5 70.19; ALE Near-term (67 tasks) partial 84.82 vs GPT-6 Astra 82.26 (+2.56) — but ALE binary: RSIAgent 50.75 < GPT-6 Astra 52.24 (§C.4 concedes the partial-credit advantage does not extend to every metric).
  • Pack correction — it is the harness, not the models: the "Kimi-K3 and GLM-5.3 outperform GPT-6" framing is really "the RSIAgent harness (GLM-5.3 actor, Kimi-K3 verifier+curriculum, Table A3) exceeds reported single-agent numbers under non-matched protocols" (self-disclosed, Table 1 note). The w/o-RSI harness ablation already sits at 71.97/83.75 — most of the gap vs GPT-6 is the harness scaffolding; RSI memory adds 71.97→78.98 and 83.75→84.82 partial.
  • Contaminated aggregation (§C.3–C.4): the OSWorld RSI row mixes 41 non-diagnostic RSI results with retained baseline scores for the rest; ALE mixes 19 RSI + 48 baseline; exploration tasks were selected for headroom. And the curriculum agent receives the exact target query — DRS practices on the target before the scored run (target-conditioned practice; disclosed, central to interpretation).
  • Memory reality vs framing: memory is actor-authored free-form markdown with no required schema (P5/P6 merely instruct "make causal claims only when evidence supports them") — "causal memory" is aspirational; what is rigorous is the freeze: hash-recorded snapshots, eval-env copy, writeback disabled (Appendix A.3).
  • Failure taxonomy worth stealing (§4.6): unchallenged assumptions propagating into memory; verifier PASS without requirement coverage (internal PASS ≠ official credit — T049 slide 2 uncredited despite verifier PASS); unverified decisions becoming reusable rules. Audit counts are tiny (1–3 cases per subtype).

Mandatory qualifications: baselines copied from official reports/blogs (budgets, harnesses, seeds differ per row); no seed-matched memory ablation anywhere (ablation Fig 4 is n=4 tasks, full-RSI = mean of two historical runs); case studies are selected historical runs; internal verifier and some judges are LLMs (Kimi-K3 verifier; GPT-5.4 for official model-based grading; Qwen3.8-27B rubric judge in the GameCraft study where dev actor+verifier share GLM-5.3-Flash); zero cost accounting (only execution limits; memory grows to 140–317 kB/task unquantified in dollars); code/project page claimed, availability unverified.

BQAA/ADK application: closest thing this cycle to an audit-trail product spec wearing a methods paper: per-wave memory snapshots with file-tree hashes, role isolation boundaries (verifier blind to actor reasoning; curriculum gets a disposable memory copy; UNVERIFIED never promoted to a verdict), and protocol/stopping-policy/terminal-status logged per lineage. Two eval-integrity warnings for any analytics product: aggregates that mix selected improved lineages with retained baselines, and target-conditioned practice before scored runs — both are detectable contamination patterns in trace data.

2. NEW rank: Dream-RSI — completed discovery trees become a deterministic replay simulator: orchestration policies are re-scored off-policy on recorded traces at zero re-execution cost, behind an explicit anti-leakage contract

Dream-RSI: Recursive Self-Improvement through Evolving Worlds, Tong Zheng, Xidong Wu, Zheng Zhang, Zhankui He, Chaoyi Zhang, Benjamin Coleman, et al. (Google / Google DeepMind / UMD / UVA). v1 2026-09-14, Monday cycle; no v2. Full text read (36 pp) including Appendix A (task defs), B (full prompts + anti-leakage contract), C (discovered solver listing). (PDF)

Discovery history — each attempt a node carrying filesystem snapshot, artifact, eval diagnostics, score — is pooled into a replay simulator; an LLM policy-development agent then rewrites only the exploration orchestration code (models, evaluator, execution interfaces fixed), scoring each candidate policy by deterministic re-traversal of recorded trees (Eq. 1: quality − β₁·cost + β₂·parallelism), and the winner redeploys online, expanding history. Verified findings:

  • The mechanism, precisely (§2–3, Fig 2): "replay returns recorded children of the selected nodes deterministically" — this is frozen-trace re-traversal, not a learned/generative world model; policies cannot earn reward out of the recorded support (App. B.2). The Dreamer analogy is explicitly analogical. Cheap but support-bounded feedback — the honest framing.
  • Lasso solver discovery (Fig 3a, §4.1): Gemini-3.1-Pro — 317 discovery calls vs 550 under fixed exploration (1.7× fewer) at better held-out runtime (2931.0 ms vs 3587.1 ms); vs SimpleTES (GPT-OSS-120B, 51,200 generations) ≈162× fewer calls with better average runtime (3804.8 ms). Discovered solver beats sklearn (44180.3 ms) and glmnet (13767.5 ms) on all 6 held-out datasets. "Up to 162×" is real arithmetic on the cherry-picked best axis.
  • Math (Table 1): Sum-Diff 1.145427 (best of table), Circle Packing ties best — AutoCorr 1.456375 is worse than SimpleTES (1.453675) and worse than its own controlled baseline (1.456001), disclosed in-table (good faith). All under <1k generations vs SimpleTES's 51,200.
  • KernelBench (Fig 4): VGG16 2.43× and LayerNorm 1.79× fewer generations to comparable performance; ConvDiv 2.09× / ConvMax 1.44× higher score at matched budget. Curve-read, no underlying table.
  • Eval integrity done right (App. B.2): the policy-improvement contract hard-codes "never use unrevealed scores, a true optimum, hardcoded winning cell ids, or internal trace data; prefix-only decisions" — a worked example of preventing replay-peeking in self-improving loops. All evaluators are programmatic (objective checks, wall-clock, kernel correctness); zero LLM-judge circularity.

Mandatory qualifications: single trajectory per configuration — no seeds, replicates, or error bars anywhere; "discovery cost" counts discovery-agent calls only, excluding the policy-development agent's M revisions/round and β sweeps (β values never stated); replay→online generalization unanalyzed beyond the support caveat; SimpleTES comparison is cross-model and external math baselines are literature-reported; depends on unreleased Gemini-3.1-Pro/3.7-Flash and internal harness APIs (prompts + one artifact in-paper; repo claimed, unverified); the dagger SimpleTES† row is unexplained.

BQAA/ADK application: the strongest trace-replay reference this cycle — the discovery tree is literally a queryable trace store (snapshot + artifact + diagnostics + score per attempt) treated as an offline environment for off-policy evaluation of orchestration changes, with policy_execution_traces.jsonl and live_cycle_manifest.json archived as first-class artifacts. The direct BQAA question it poses: which proposed routing/budget/orchestration changes can be scored by deterministic re-traversal of logged session trees before any live rollout — and the support bound says exactly when that estimate is meaningless (policies that would generate genuinely new behavior).

3. NEW rank: Atria Dawn — a 769-task, 56-participant telemetry study of human oversight over agent work: AI proposes (55.4% of method decisions) but humans hold final authority (85.5–93.4%), and intervention is context, not takeover (0.7%)

Atria Dawn: The Dawn of Agentic Superintelligence, Honglin Guo, Tao Gui, Yicheng Chen, Guanting Dong, et al. (~140 contributors; correspondence Fudan). v1 2026-09-14, Monday cycle; no v2. Full text read (23 pp) including Appendix A (contributions) and B (eval protocols). (PDF)

Carded for the §4 human–AI collaboration study, not the wrapper: the paper is a vendor model announcement (Atria Dawn Preview, a 744B-MoE-based agentic model with a one-page "Verifiable Experience Pipeline" recipe and a self-reported 16-benchmark table) stapled to a genuine oversight-telemetry dataset — 769 task records from 56 participants alongside agent logs from the team's own R&D. Verified findings:

  • Oversight load is rising (Fig 6): agent actions per human prompt, daily median 11.0 → 28.5 over Aug 7–Sep 4 (21–22 participants/day; IQR shading explicitly disclaimed as a CI). The paper's own warning: each human judgment now propagates through more agent actions, not fewer.
  • Decision attribution (Fig 8; n=603 goals / 567 methods / 542 acceptance): "AI proposes, human selects" = 55.4% of method decisions; humans hold the final choice on 85.5% of methods, 93.4% of goals, 81.9% of acceptance; AI final decision only 6.1–9.2%. On the 151 tasks rated infeasible-without-AI, humans selected the goal in 95.4%.
  • Counterfactual dependence (§4.1): of 455 completed AI-assisted tasks with usable responses, 151 (33.2%) were rated infeasible without AI — spread across 27 of 56 participants (a self-report distribution, not a population estimate).
  • Intervention taxonomy (Fig 9; n=588): 76.0% of difficulties resolved by human intervention vs 23.0% agent self-recovery; modes: context/clarification 35.2%, diagnosis/method change 34.7%, partial edits 3.2%, takeover 0.7% — human help is ~18× more likely to change what the agent knew than who did the work.
  • Output disposition (Fig 10; n=627): 56.5% of agent outputs substantively revised, 95.9% entered the deliverable; within revised tasks, the AI itself made the revisions after human feedback in 75.4% vs 19.2% direct human edits.

Mandatory qualifications: single-team self-study building the very model being announced; retrospective participant recall/estimates; no inferential statistics anywhere (no CIs, no tests — Figure 6 explicitly disclaims); survey instrument never shown. The §2 wrapper is marketing: the 16-benchmark Table 1 is self-reported release-site data with comparison numbers not re-run, and there is real judge conflict — glm-5.3 judges GDPval where GLM 5.3 is itself a competitor (Appendix B, which is otherwise admirably transparent: judges, seeds, timeouts, contamination controls). "Superintelligence" appears nowhere as a technical claim — §3.2/§5 actually argue against imminent RSI. The Verifiable Experience Pipeline is a one-page recipe, not a method.

BQAA/ADK application: §4 is essentially a HITL oversight telemetry schema derivable from agent logs: agent-actions-per-human-prompt as an oversight-load metric, a propose-vs-select decision-attribution split separating suggestion volume from decision authority, and an intervention-mode taxonomy (context/clarify vs diagnose vs edit vs takeover) distinguishing steering from takeover — all mappable to audit columns on BQAA human-in-the-loop paths. Appendix B doubles as an eval-integrity disclosure checklist (judge model, seeds, timeout budgets, contamination stripping).
