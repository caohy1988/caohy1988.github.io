2. NEW rank: GAVEL: Graph World Models for Verified and Efficient Long-Horizon LLM Task Planning (arXiv:2609.19315) — an explicit graph world model rolls each LLM-proposed plan forward before execution, repairs deterministic failures without an LLM call, and escalates only semantic failures: 41.2%→91.8% on BEHAVIOR-1K single-task with fewer LLM calls (1.5 vs 2.7), and a Qwen3-4B+harness beats bare frontier models (75.2% vs 24.6–38.6%)

v1, submitted 2026-09-16 (single version). Wang, Hsu, Mehta, Kim, Dou, Pajic (no affiliations printed in the v1 PDF; attribute cautiously). HF Daily 2026-09-21. Abstract numbers claim-checked against Tables I–III — all verified, with one ablation mislabel corrected below. All main results are mean±std over 5 seeds (unusually honest for this genre).

  • The method: the graph world model tracks object relations, action preconditions/effects, and probabilistic beliefs over unobserved locations. LLM plans are verified against it pre-execution; failures whose fix follows from action semantics are repaired deterministically, zero LLM calls; only semantic failures go back to the LLM.
  • Headline (verified): BEHAVIOR-1K symbolic single-task (100 tasks, Qwen3-8B): llm-only 41.2±1.2% → SayPlan-style feedback 76.4±1.5% (2.7 LLM calls) → GAVEL 91.8±1.3% (1.5 calls); the graph-repair-only variant alone hits 76.2% with 1 call. Multi-task (500 instructions): 19.9% → 92.6%, distance 83.0→78.0m vs SayPlan. Scaling (Table III): GPT-5.6-Sol alone 24.6%, Claude Sonnet 5 alone 38.6%, Qwen3-4B + GAVEL 75.2%; hosted models + GAVEL ~99%.
  • Corrected/qualified numbers: the abstract's "≈5.4% vs a static variant" is mislabeled — the 5.4% (82.45→78.01m) is vs gavel-map (collapsed belief), not gavel-static; vs the actual static variant the gain is ~2.1%. And gavel-map/static/full all score identical 92.6% success — belief reasoning buys distance efficiency only, zero success gain. Evaluation is symbolic planning in a 2-D executor, not physics (validated against OmniGibson on all 100 single tasks at 100% outcome agreement; no motion-level feasibility, no real robot). Baselines (SayPlan, EPoG) are re-implemented in the shared pipeline, not original-code runs. The 38 residual multi-task failures are mostly instruction-grounding (21 object-extraction) — grounding, not planning, is now the bottleneck (authors admit).

TL;DR for BQAA: the cleanest current demonstration of "verify before execute, repair deterministically, spend model calls only on semantic failures" — the architecture BQAA's trajectory-auditing story assumes, here with unusually honest ablations (repair-only vs feedback-only vs full). The small-model+harness-beats-bare-frontier result is the quotable argument for verification infrastructure over raw model scale. Transfer caution for our domain: the world model is hand-structured for household-state graphs; the software-agent analog (repo/tool-state world models) is the open work.
