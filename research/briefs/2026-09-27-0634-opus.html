1. NEW rank: arXiv 2609.17464: Decomposition Buys Integrity, Not Yield

Author: Rong He (single author). v1 15 Sep 2026 (cs.MA), 18 pages.

  • Code, plus an audit.py that "re-derives every numeric assertion", ship as arXiv ancillary files. I read the README and did not run the scripts.
  • Claude is disclosed as a research assistant.

Full PDF read: §1–10 and the reproducibility appendix (Tables 1–7, Figs. 1–8).

What they did:

  • The model.
  • A task needs N findings. An agent handed b items keeps each with probability r(b).
  • With r(b) = C·b^−δ, a depth-k tree yields C^k·N^(1−δ) (Theorem 2). Task size and architecture separate, and each tier only multiplies yield by C ≤ 1.
  • So, for yield alone, a flat agent is optimal (Theorem 3).
  • What depth buys instead. The root's context is the only one that persists and cannot cheaply forget. Depth cuts what it absorbs from N items to N^(1/k) (§5).
  • Three corpora, all analyzed on a laptop CPU:
  • 600 deep-research traces (23,026 searches, 11,889 extraction requests);
  • 743,819 production tool calls across 8,058 Claude Code and Codex sessions, released with the author's earlier context-eviction study;
  • 1,012 usable MAST multi-agent traces with annotated failure modes.

Key numbers:

  • Crowding (§4.1).
  • δ = 0.341 [0.298, 0.384], from a per-item hazard over 98,768 surfaced URLs.
  • Surfacing four times as many sources means carrying only 2.3 times as many forward.
  • With 200–400 URLs in context, 22.2% of picks land on the newest ten, against 3.8% under uniform choice (Table 1).
  • Per-tier retention (§4.2). C = 0.571 [0.527, 0.615] over 16,082 hops. It is observed directly at b = 1 (550 hops), not extrapolated (Table 3).
  • Briefing loss (§4.3).
  • One agent-to-agent brief in sixteen goes off-target (µ = 0.939 [0.935, 0.960], Table 4).
  • Two tiers keep 53.6% of a flat agent's findings, three 28.7% and four 15.4%.
  • Token bills (§6).
  • A session's input tokens grow as rounds^1.392 ± 0.004 over 6,567 sessions (Claude Code 1.450, Codex 1.337). Append-only context would predict 2; agents compact.
  • Sessions that compact also delegate more: 20.7% vs 8.7% at 40–160 tool results.
  • One delegation costs about 7,694 characters (2,640 brief, 5,054 returned).
  • At equal spend, two tiers overtake flat at 403 findings.
  • Production (§7):
  • tool calls error 4.60% (Claude Code) and 4.88% (Codex) of the time;
  • when context collapses, a median 15.2% of it survives (4,892 events);
  • 563 of 7,244 sessions (7.8%) ever spawn a subagent;
  • 74.5% of spawning rounds spawn exactly one, mean fan-out is 1.49, and there is no deeper nesting.
  • Delegation is an opening move (Table 6).
  • Over 502,718 session-rounds, doubling accumulated context multiplies the odds of delegating by 0.969 [0.954, 0.985].
  • Rounds elapsed is strongly negative (z = −18.0).
  • The measurement trap (§7).
