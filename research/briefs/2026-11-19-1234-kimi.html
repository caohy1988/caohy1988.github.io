Read this first

  • Tool governance is converging on the same evidence shape. LangSmith Tool Gateway adds identity, policy and approval context to tool traces; AgentCore adds deterministic lifecycle hooks; Skyflow puts bidirectional data protection at the gateway. BQAA should join these as actor → policy decision → tool outcome → downstream effect, not as disconnected security logs.
  • Cost accounting is moving from invoice totals to workflow economics. Pinecone exports project/index spend in FOCUS, Langfuse enforces budgets at the gateway, and Accenture reports cost per successful business transaction. The right comparison is cost, quality and outcome together; a cheaper token or a smaller bill alone does not establish improvement.
  • The strongest Academy result is a measurement warning. In a 0.99B-token trace, 94.8% was cached-context reads and parent logs undercounted delegated tokens 10×. Separately, the CI/CD authority paper offers useful control-plane tagging but its compound risk score partly manufactures the reported separation; treat it as a triage hypothesis, not a validated risk scale.
  • Decision: PUBLISH. 5 Industry NEW, 3 material Progress notes and 3 Academy NEW. Date-only Mastra Gateway and proactive-evaluation posts, the future-dated Google roundup, and every failed lookup stay out of the ranked set.

Industry

NEW

  1. LangSmith Tool Gateway (Public Beta) — identity, policy and approvals join the agent trace. Launch post (RSS 2026-11-19T15:51:28Z). Tool kits expose curated MCP tools through one URL; calls can use the end user's or agent's credentials, with deny rules and human approvals. LangSmith traces record tool, server, user, outcome and duration without storing tool payloads, while Enterprise audit logs answer which tool ran as whom. BQAA: this is a clean join key from agent intent to authorized action and result; keep payload minimization distinct from evidence completeness.
  2. Amazon Bedrock AgentCore harness adds Strands defaults and deterministic lifecycle hooks. AWS launch post (RSS 2026-11-19T20:01:06Z). Managed defaults now cover model/instructions, prompt caching, context summarization and offloading, planning, web/filesystem tools and delegation. Lambda can deny at four lifecycle points, SNS/EventBridge can notify, decisions appear as hookEvents, and subagents inherit tool-call hooks. AWS says the Strands-backed rollout began November 11 and claims about 34% lower token cost than other leading harnesses without a methodology in the post, so treat that figure as vendor-reported rather than a benchmark result.
  3. Skyflow + AgentCore Gateway moves sensitive-data controls into request/response interceptors. AWS partner walkthrough (RSS 2026-11-19T18:14:36Z). The open-source interceptor tokenizes sensitive values before third-party tools or the model see them, restores authorized results, swaps document URLs for cleaned copies, fails closed and logs decisions to CloudWatch. String de-/re-identification is GA; signed-URL document de-identification uses Skyflow Detect v2 in preview. BQAA: gateway traces need a data-protection decision and transformation lineage, not only prompt/response text.
  4. Pinecone Cost and Usage Export API brings project/index spend into FOCUS. Launch post (JSON-LD 2026-11-19T16:00:00Z). Enterprise organizations can export up to one year of cost and usage as zipped FOCUS v1.4 CSV, through the console or Admin API, with project, resource, index and tag fields for chargeback and warehouse/FinOps ingestion. It does not attribute spend to an individual agent run by itself, but supplies the missing billing join for agent workloads that annotate those dimensions.
  5. Grafana Notebooks turn dashboard and Assistant output into a reviewable evidence package. Launch post (RSS 2026-11-19T15:22:49Z). Public-preview Notebooks combine live panels, Explore queries and Grafana Assistant-generated visualizations with a written hypothesis, evidence and next test, then share that working document for rollout decisions or incident review. The useful boundary is explicit: AI can help assemble the analysis, while readers still reproduce and judge the claim.

Academy

NEW

  1. Re-Reading Is Not Free: Token Traces and Cache-Aware Energy Estimation for LLM Agents in Software Engineering. Full 21-page PDF read, including all methods, results, limitations, references and Appendices A–F / Tables I–XVIII. The 42-session, 752-episode, ten-week trace contains 992,549,044 deduplicated API-reported tokens: 94.752% cache reads, 0.017% uncached input and about 260 cached reads per generated token (Tables I and III); context grows 5.3× over a session versus 1.4× within an episode (§III-A). Parent reporting captures only a subagent's final internal call and undercounts delegated tokens 10×, while the cache-aware model estimates 248 kWh versus EcoLogits' 9.89 kWh (Table IV). The energy figure is not metered and extrapolates beyond long-context validation; the solid BQAA lesson is to retain all four token classes and reconstruct delegated execution before doing cost or energy analytics.
  2. Who Changed the AI Agent's Rules? Measuring How AI Coding Agents Escalate Authority in CI/CD Pipelines. Full 16-page PDF read, including methodology, Tables 1–5, threats to validity and references. Across 932,791 AIDev PRs, 37,409 (4.0%) are classified control-plane; their mean joint penalty is 0.498 versus 0.218 data-plane (2.3×) and governance risk 0.530 versus 0.135 (3.9×), with policy flags on 63.6% of merged control-plane PRs (Tables 3–4). Authority classification uses title/body keywords validated on only 34 PRs (94.1% agreement, Cohen's κ 0.72), while the score adds a 0.25 control-plane premium and defines policy violation only for control-plane PRs. Thus the all-775-extreme-risk and separation results are partly structural, not independent evidence of real-world authority abuse; adopt diff-based control-plane tagging and approval routing, not the uncalibrated score as ground truth.
  3. Where the Tokens Go: Heat, Entropy and Error in Agentic Coding. Full 43-page PDF read, including every method/result/limitation section, references and Supplementary Notes/Figures/Tables 1–11. Over 1,200 coding/uncoding runs (1,110 landed), about 80% of landed-run output tokens leave the requested edit state unchanged; estimated free energy is 14–22% of landed coding cost (Table 8). More operationally, 78 turn-limit-stopped runs generated 65.6% of all tokens and 75 of them repeated one or two searches (§4.4). The thermodynamics is explicitly an analogy over one model, one private repository and two renaming tasks, and the authors caution that much “heat” buys useful information; use progress deltas and loop evidence to expose wasted spend, not a universal token-value law.

Six-week EV

  • Tool-action evidence and identity (high EV, 2–3 weeks). Extend the event model with actor identity, credential principal, tool server, policy decision, approver, outcome and duration. Join gateway hook/interceptor events to the same invocation and subagent tree; test that delegation cannot bypass policy and that redaction still leaves an auditable decision trail.
  • Whole-workflow cost ledger (high EV, 1–2 weeks). Store uncached input, cache writes, cache reads and output separately for every model call, and reconstruct subagent usage from child transcripts rather than the parent result. Add business-outcome and FOCUS/billing joins so cost per successful task includes retries, tools and failed attempts.
  • Budget and routing telemetry (high EV, 2 weeks). Emit budget limit, scope, reset, rejection and fallback events per key/user/org alongside quality and outcome. Evaluate one optimization at a time on held-out production traffic; do not infer savings from list-price discounts or aggregated multi-lever case studies.
  • No-progress and gate-reliability analytics (high EV, 3–4 weeks). Detect repeated actions with unchanged target state and keep failed runs in cost denominators. For proactive agents, log act/wait/stay-silent decisions, including no-output runs; for test/eval gates, measure clean-run noise, false landings and independent-verdict disagreement before setting automation thresholds.
  • Authority-scope review (high EV, 3–4 weeks). Classify workflow, permission, approval and deployment-policy changes from file diffs, not PR prose alone, and require accountable approval for control-plane edits. Treat compound risk weights as configurable triage until validated against actual review and incident outcomes.
  • Evidence-package review (medium-high EV, 3–5 weeks). Prototype a notebook-like run review containing the hypothesis, live query evidence, agent-generated analysis and the next falsification test. Preserve reader reproduction and sign-off so an AI-written explanation cannot become self-certifying evidence.

TL;DRs for BQAA

  • LangSmith Tool Gateway: identity, approval and outcome fields turn tool governance into joinable agent evidence; payload-free traces still need policy context.
  • AgentCore harness: deterministic lifecycle hooks and inherited subagent checks are directly reusable as control points; the 34% cost claim is unbenchmarked vendor evidence.
  • Skyflow interceptor: sensitive-data transformation belongs in the tool-call lineage, with GA text controls distinguished from preview document cleaning.
  • Pinecone export: FOCUS project/index exports solve the billing side of agent cost attribution, but run-level identity must come from traces.
  • Grafana Notebooks: the useful agent-observability artifact is a reproducible evidence argument, not an Assistant summary alone.
  • Langfuse Progress: gateway rejection on per-key/user/org budgets creates an enforcement event worth tracing beside spend and quality.
  • Foundry Progress: distinct agent identities, permissions and managers remove borrowed-user ambiguity from multi-user audit trails.
  • AWS/Accenture Progress: measure fully loaded cost per successful business outcome; multi-lever 40–85% case-study savings are not isolated treatment effects.
  • 2611.20873: cached reads dominate raw token volume and parent-only subagent records can be 10× low; absolute energy remains model-based and unvalidated for these contexts.
  • 2611.23251: control-plane PR tagging is valuable, but the paper's risk premium and control-plane-only policy flag make parts of its headline separation circular.
  • 2611.23375: repeated no-progress loops consumed most tokens in this experiment; split productive investigation from stagnation before calling all non-edit tokens waste.
