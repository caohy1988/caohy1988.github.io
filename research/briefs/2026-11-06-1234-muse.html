Full-PDF count: 2 of the 3-paper cap, plus one partial.

  • Attributing Agent Failures to Their History Needs an Executed Counterfactual (2611.05650, reserve from an earlier batch, submitted 3 Nov 2026; NeurIPS 2026 workshop paper) — full PDF read; stays reserve, not ranked. The proposal is a reporting standard: a claim that an agent failed because of its history should be verified by continuing the same agent from a frozen executable state with only the visible history changed (healed, provenance-swapped, placebo/length-matched, or counterfactually injected), backed by a measured replay certificate against an unedited live-vs-restored control (§2, §5). The strongest concrete result is a replay-fidelity warning: hash-identical snapshots restored into seeded processes agreed with each other in 24/24 states while diverging from the live continuation in 9/24 and 20/24 states at tool-failure rates 0.05/0.20, because the snapshot omitted the random-stream position; capturing it removed all divergence (0/24), and final-grader outcomes never flipped, so an outcome-only check would have hidden the defect (§3.2, Tables 3–4, Appendix B). The companion measurement is an honest null: a failure-carrier taxonomy's 84.9% "concentration" tracks benchmark task allocation (adjusted OR 1.148 [0.627, 2.016]) and was declared non-evaluable under the authors' own pre-outcome guard (§3.1, Table 1, Appendix A). Why not a rank: by the authors' own Discussion (§4), neither measurement establishes a behavioral result — one is non-evaluable, the other model-free (no LLM in the loop, 24 factorial states) — and the decisive history-arm experiment is an unrun design (Appendix D). The replay-certificate norm is the right requirement to attach to any future BQAA replay/fork feature (it sharpens the Trace2Eval line already carded), but a standard proposal plus cautionary measurements, however careful, does not clear this brief's bar for an evidence rank. Revisit only if the Appendix D design or an equivalent intervention study is actually run.
  • Closed-Loop Agent Evaluation: Layered Measurement and Self-Calibration (2611.07051, Friday-batch scout head, submitted 4 Nov 2026) — full PDF read; not ranked. The closest architectural match to a production eval warehouse in recent batches: four levels (span/trace/conversation/engagement), atomic checkable judgments separated from deterministic versioned-rule analysis, cross-model agreement admission (κ ≥ 0.60) before any datum enters scoring, censored-outcome handling instead of imputing success, an inner loop that audits the evaluation itself and an outer per-component regression gate (§2, Tables 1–2). The case evidence is real but narrow: one Chinese-language business-analysis agent (8,537 real turns; judged components on 107 stratified sessions), where evidence-and-rule judgment beats holistic scoring modestly (ICC 0.86 vs 0.81; outcome κ 0.81 vs 0.63), seven inner-loop corrections are documented (Table 3 — e.g., full-text evidence moved a report score 0.92 → 0.79), and the regression gate is validated only offline (A/A false alarms 98% per-turn vs 4.5% user-clustered; 80%-detection thresholds from +1.5pp to +35.5pp by metric, Table 4). The portability test is 60 public conversations with keyword rules explicitly not transferring (§5). The authors state the limits themselves (§7): one agent and language, small judged sample, agreement is not correctness (no human gold set), outer-loop fixes "not yet live," implementation still offline batch. That is a well-built framework paper whose empirical base remains a single case — below the bar set by this week's ranked measurement papers. It stays the first design reference if BQAA's eval roadmap opens a closed-loop/adjudication workstream; it does not need re-screening, and it should not be carded from this mention.
  • The Two-Ledger Model: Transaction-Grain Cost Accounting for Multi-Agent AI Systems (2611.06989, Friday-batch scout, submitted 4 Nov 2026) — partial PDF read (see statement above); not ranked. Joins a settlement-grain FOCUS billing ledger to an invocation-grain attribution ledger built on OpenTelemetry GenAI telemetry, with a layered correlation spine and a reconciliation residual meant to surface unmetered ("shadow") AI spend. The validation the paper itself describes is analytical plus a simulation on synthetic data with known ground truth (coverage >99%, residual recovery within 0.24pp in-simulation), and the text states plainly that there is no field deployment and a field pilot is the next step. Warehouse-adjacent and well-formed, but a simulation-only cost-accounting architecture does not clear the rank bar; revisit on field data. Pairs conceptually with the already-carded per-span token-waste measurement (2611.07238) if FinOps attribution becomes a BQAA requirement.
  • Same Rule, Different Verdicts: rubric language and clause structure in LLM judges (2611.04091, older reserve, submitted 3 Nov 2026) — abstract-screened only; unchanged disposition. 51,744 judge requests: lower cross-provider agreement under Korean rubrics (κ 0.687 vs 0.745), disagreement concentrated in negated/conditional/exception clauses (OR 5.6), same-meaning rephrasings flipping 11–15% of verdicts. Clean design, but consistency without human labels in a support-dialogue scope stays below the rank bar, as judged at the 0034 slot. The practical residue for BQAA judge-prompt authors (prefer atomic affirmative clauses; treat negation/exception clauses as disagreement hotspots) is already recorded; no PDF read was spent here because the abstract-level limitation is dispositive.
