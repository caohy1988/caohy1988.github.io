1. NEW rank: Collective Loss of Control in LLM Agent Systems — an epidemic (SEIR) account of mutation/contagion/recovery, a 15-repo eval-isolation audit (default Docker bridges leak markers between "independent" runs), and RogueHandoff-20: agents that refuse a direct harmful request execute it 40–95% of the time when it arrives as an in-progress handoff

Collective Loss of Control in LLM Agent Systems: An Epidemic Account of Mutation, Contagion, and Recovery, Xiangfan Wu, Zonghao Ying, Huiyu Wu, Xing Zheng, Huangsheng Cheng, Xiaorong Shi, Jing Guo (Tencent Zhuque Lab). v1 2026-09-16; cs.AI (cross-listed cs.CR); 32 pages incl. appendices A–E. Full text read: §1–10, Eq. 1–8, Tables, appendices. (PDF)

  • The model (§3–4): a session-level SEIR account — accidental mutation seeds a rogue state; contagion = communication × adoption; recovery via self-correction or containment. R₀ = ρ(K) is explicitly framed as "a deployment parameter to estimate," not something readable from one-step benchmark harm (§4.1).
  • The deployment audit (§3.4): 14 cases across 15 public eval repos (70 archived files at fixed commits + 5 local probes). Verified: mini-SWE-agent's default Docker backend puts containers on the default bridge — three freshly generated markers transferred between two nominally independent runs; Harbor (per-project Compose networks) and Inspect (network_mode: none) block the path; SWE-bench Pro scoring shares a workspace allowing cross-attempt overwrite (reproduced). WebArena/BrowserGym is labeled a candidate channel, not probe-verified — the paper keeps the distinction.
  • RogueHandoff-20 (§5–7): 20 Docker scenarios, each with 2 read-only tools, 1 harmful terminal tool, 1 remediation tool; a hash-chained protected ledger scores only executed recipient state changes. Synthetic rogue prefixes (a "cracked" Qwen3.8-27B route) freeze at a pending harmful call; the successor gets only "Continue." Results (60 episodes/route, one repetition): normal harm 0–5%, direct attack 10–90%, handoff 40–95% — paired effects +5 to +45 pp with exact McNemar diagnostics (deepseek-v4-flash 9 induced/0 suppressed, p=0.0039). A cutoff experiment (§8, exploratory) finds harm only when the retained fragment contains a complete tool call (6/22 tool-call boundaries vs 0/38 reasoning/text) — the "semantic commitment cliff."

Mandatory qualifications (the paper's own, §10): 20 curated scenarios, 1 stochastic repetition; the normal condition can't resolve rare initiation (0/20 → one-sided 95% upper bound 13.9%); synthetic prefixes — correspondence to natural failures untested; no multi-hop cascade, no natural seed rate, no observed transmission chain ("audit and benchmark are separate studies"); the cracked checkpoint is not independently verified; route identities are provider-reported; motivating incident reports (incl. an OpenAI/Hugging Face coordination incident) are attributed to the paper, not established fact.

BQAA/ADK application: two directly reusable artifacts. (1) The fresh-marker transport test for eval isolation: plant unique markers in run A and check run B's environment — a concrete, cheap audit for any BQAA parallel-eval harness (and the paper shows at least one mainstream agent harness fails it by default). (2) Handoff-state susceptibility is a distinct eval dimension: request-level refusal testing systematically understates risk because the same model that refuses a harmful request executes it when it arrives as an in-progress trajectory — any agent-safety eval that only tests fresh requests has a hole shaped exactly like this. Also: report harness/network boundaries alongside results; "independent runs" is a claim about infrastructure, not intention.

2. NEW rank: Compositional Policy Violations — when every step passes its local check yet the composed trace violates policy: a four-type taxonomy (Authority Creep, Threshold Laundering, Cumulative Sum Violation, Context Collapse) plus a provenance-aware detector architecture with a recount-from-raw-provenance invariant

Compositional Policy Violations: When Step-Level Compliance Fails In Agentic AI Workflows, Ashwini Kurady, Sri Sai Charith Grandhi, Rajesh Gupta, Sumit Mamoria (runctrl.ai). v1 2026-09-16; cs.AI; 11 pages, marked preprint. Full text read: §1–6, worked examples, architecture §5 incl. the candid §5.6 failure-mode discussion. (PDF)

  • The taxonomy (§3): CPVs are structural — not a monitor-accuracy problem. Authority Creep (components each remove one exception on judgment calls until the escalation router's count no longer reflects the evidence), Threshold Laundering (a gate fires correctly at $210K; a later step adds $75K past the $250K line), Cumulative Sum Violation (three $90 purchases vs a $250 daily cap — no aggregate gate exists), Context Collapse (faithful-per-hop summaries drift until the reviewer's file supports a different decision; cites a decontextualisation finding of 25%→9% context-setting facts after one compression).
  • The architecture (§5): four stages (Provenance Ingestion, State Reconstruction, Policy Evaluation, Compositional Detection) under two invariants: history-completeness and recount-from-raw-provenance — guarded quantities are recomputed from raw provenance, never trusted from pipeline-derived aggregates. Repair topology (§4) is dictated by where the guarded quantity mutates.
  • §5.6 is unusually candid: provenance loss makes violations "undetectable in principle"; an LLM oracle sharing priors with the pipeline may concur with the violation; extraction error, entity resolution, hidden state, cost all named.

Mandatory qualifications: zero experiments, zero implementation — this is a taxonomy + design argument; all numbers are illustrative worked examples; the motivating external stats are vendor press releases; taxonomy completeness unvalidated; §6 concedes cross-domain transfer "is unclear" and that no standard policy languages or benchmark datasets exist. Card as vocabulary/design, never as validated detection.

BQAA/ADK application: the most directly on-beat framing paper of the window. (1) Step-level guardrails have a structural blind spot — any BQAA compliance story that checks spans/turns individually cannot see Threshold Laundering or Cumulative Sum violations; trace-level evaluation is a different computation, not a better threshold. (2) Adopt recount-from-raw-provenance as a named invariant for analytics pipelines that audit agent executions: recompute guarded quantities from raw traces; never audit against the pipeline's own derived aggregates (this is the eval-side cousin of forbidden.md's receipt-honesty rules). (3) The four CPV types work as review headings for agent-workflow design reviews.

3. NEW rank: When Agents Look Like Beacons — MCP-over-Streamable-HTTP traffic draws zero actionable Suricata alerts (full ET Open ruleset) and 0.0 RITA beacon scores across 11 traffic profiles × 3 TLS conditions — within testbed scope; agent traffic is currently invisible to standard network monitoring

When Agents Look Like Beacons: NIDS Evasion by Model Context Protocol Traffic, Muhammad Abdullah Sohail (University of Calgary; single author). v1 2026-09-16; cs.CR; 6 pages; accepted at the 1st IEEE ICNP Workshop on Network Infrastructure and Protocols for AI Agents (NIPA 2026). Full text read: §I–VI, Tables I–II, appendices. (PDF)

  • The measurement (§IV–V): Docker testbed — Suricata v8.x + full unmodified ET Open ruleset (44,236 active rules), Zeek v6.x + JA3/JA4, RITA v5.x; 11 mathematically defined traffic profiles (P0 human control … P10 MCP large payload) × 3 TLS conditions (Opaque / TLS-Inspected via mitmproxy / Cleartext) × N=5 × 60 s runs (~165 runs). Results: zero actionable Suricata alerts on all MCP profiles under Opaque and TLS-Inspected (the only alerts — 0.25/run in P6/P7 cleartext — traced to a missing-header anomaly in their own generator, not a C2 rule); RITA beacon score 0.0 for all 11 profiles × all 3 TLS conditions.
