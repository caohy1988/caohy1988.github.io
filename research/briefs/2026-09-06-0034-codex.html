Academy

1. Ignorance or Incompetence? — controlled knowledge access and execution tests (arXiv:2608.30322)

Hanlin Tian, Minhao Li, Yu Mi, Sihan Zhu, Zhao Yang, Yuxiang Wang, Hongquan Zhu, and Qiufei Hu; August 31 v1. Full 17-page PDF read, including appendices.

The construction holds task instructions fixed while providing or withholding a private knowledge artifact. All 15 evaluated tasks use executable verification. Opus 4.8 with Claude Code passes 51/75 provided-artifact runs versus 0/75 without it. This establishes dependence on supplied information in the tested configuration. PDF, task construction and results.

The more useful diagnostic is a reduced two-task probe: Qwen correctly recites and applies conventions in 20/20 conversations, while its full agent harness passes 0/5 on each task. The reduced setting also changes data exposure and execution demands, so it suggests a harness or execution problem without isolating its cause. Model comparisons change harnesses too, and inherited execution budgets are not pinned. The public release contains five of the fifteen tasks; it does not reconstruct the full evaluation. PDF, diagnostics and release scope.

BQAA TL;DR — analyzer recommendation: add a small matched-artifact fixture to existing memory-use evaluation: correct artifact, absent artifact, and a deliberately incorrect artifact, with the same task and verifier. Record what was supplied, what entered the context, and the executable outcome. A separate recitation check can guide investigation; it should not automatically label a production failure as incompetence. This adds a controlled availability/correctness test beyond MemoryLACE's temporal interpretation and context-packing checks.

2. Small Language Models as Judges for Rubric-Based Reinforcement Learning (arXiv:2608.30005)

Fengyu Xie, Yilun Zhao, Bingsen Chen, Arman Cohan, and Chen Zhao; August 30 v1. Full 25-page PDF read, including appendices and prompts; the abstract's nine-page comment is not the retrieved PDF's total length.

A linear probe on a frozen Qwen3-1.7B judge predicts individual criterion satisfaction from hidden states. RaR-Science-Static macro-F1 is 0.835 versus 0.443 for the same backbone generating verdicts. The target labels come from GPT-4o. PDF, Table 3.

In the controlled RL comparison, the 1.7B probe produces a policy scoring 0.643 versus 0.594 with an 8B generative judge. These use one training seed and 100 reserved evaluation prompts; reported bootstrap intervals overlap. The strongest static probe is not the strongest RL reward model. The human preference audit compares the probe-trained policy with the untrained base, not directly with the 8B-judge policy. PDF, Tables 5 and C.1–C.4.

The 10.7× reduction measures cumulative judging time. Elapsed RL time changes from 11h11m56s to 8h51m47s, a 1.26× ratio calculated from the reported times. Concurrent judge calls and other training work explain the difference. PDF, Table 8 and Appendix C.4.

BQAA TL;DR — analyzer recommendation: consider a bounded judge comparison inside existing review-budget and cross-criterion evaluation. Preserve criterion scores, evaluator version, calibration data identity, disagreement examples, and end-to-end latency. Require an independent human audit on the intended trace task before substitution. The new question is whether a criterion probe preserves useful decisions within the budget; the result does not justify collecting production model activations or promise a tenfold workflow saving.

  • WHALE — hold for the existing model/harness comparison backlog. 2609.00196, Haechan Kim, Yoonho Lee, Gisang Lee, Chelsea Finn, and Kangwook Lee; August 31 v1. Targeted reading of the 28-page PDF, Algorithm 1 and §§5–6, verifies alternating weight and executable-harness updates on three domains with 2B/4B agents.   • ESPO — hold after a full 17-page PDF read. 2609.04197, Lihao Liu, Peng Tang, Kunwar Yashraj Singh, and Shabnam Ghadar; September 3 v1. Error diagnosis, four proposal strategies, and bootstrap selection are a plausible prompt-search recipe. The PDF's Table 1 and appendices include stronger-seed and alternate-proposer checks; dismissing it as only a weak-seed result would be inaccurate. However, Table 1 combines a primary run with standard deviations from additional runs, and Table 3's Qwen averages disagree with the accompanying prose. The −1.20-point diversity-only result is Tweet-specific; the multi-benchmark appendix reports a positive average. Bootstrap resampling of the same validation examples does not create independent validation evidence. BQAA TL;DR: retain the diagnostic idea for existing prompt-evaluation work. Reconcile reported aggregates and test on held-out tool-session failures before adopting this selection method; the paper does not establish that transfer.
