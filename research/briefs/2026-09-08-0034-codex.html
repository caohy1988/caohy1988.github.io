A1. RevPropBench: did the correction reach every dependent field? — arXiv:2609.03254

NEW Academy rank — delayed adjudication. Daisuke Kikuta's What Else Needs Fixing? Exploring Cost-Effective Test-Time Compute for Revision Propagation in Artifacts Generated Through Conversation is September 3 v1. The 20:32 pack supplied the pointer. The full 17-page PDF, including appendices and prompts, was read in this catch-up.

Evidence. RevPropBench uses 150 synthetic conversational JSON cases: 50 scenarios at three artifact sizes, split into 30 development and 120 test cases by scenario. Dependencies can live in the conversation rather than the final artifact. Evaluation checks the resulting state against annotated values, matchers and optional edits; it separates omissions, unwanted edits and wrong values. With five total calls, SELECT uses four candidates plus one selection call. Reported completion rises from 93.0% to 96.3% for GPT-5.4-mini and 68.3% to 80.8% for Qwen3.5-9B, averaged over five seeds. Full PDF, §§2–4 and appendices.

Limits. Deterministic synthetic dependencies and one annotator assisted by an LLM limit external validity and label independence. Completion is not unrestricted semantic correctness. Local-model dollar costs use API-price proxies; the recommended three-candidate configurations differ from the five-call comparison above. Configuration guidance is derived from the reported curves, not separately validated on enterprise tasks. Human-review safeguards are proposed, not experimentally demonstrated. PDF, limitations and appendices A–F.

Artifacts. The public repository README documents the annotated dataset, evaluation commands, cached paper outputs and extension mechanism. Its root lists benchmark, methods and result directories, and the README states research-purpose restrictions on code use. Nested dataset/archive retrievals failed; this run did not inspect their contents, execute the benchmark or reproduce the figures. PDF screenshots were unavailable; the review used the complete extracted PDF text.

Why this clears the narrow card bar: the contribution is an operationally defined revision failure and an inspectable evaluation procedure. Cataloged EquiReview concerns review concerns/dispositions; feedback-conditioned judging concerns the evaluator's judgment. Neither already covers consistency of dependent artifact state. Raw ID, title, author and slug searches found no prior rank, progress entry or standing Astra exclusion for this paper. This admits a benchmark, not a general claim that extra calls improve agents.
