Trace as State: Reasoning Traces as Conditional States for Long-Context Transformers — arXiv:2609.02702

ACCEPTED PROGRESS on arxiv-2609-02702-trace-as-state; retain its existing Academy rank. Xu Zou, Z.ai; Jie Tang, Tsinghua University. The primary history remains September 2 v1, 15:06:46 UTC. The full PDF supplies the following qualification beyond the manually added abstract summary.

What the experiment changes. A model first generates reasoning text on the same problem. The authors serialize five source traces in repeat order, cap each at 50,000 characters, and exclude separately returned final-answer fields. A fresh pass receives either [trace, context, question] or [context, trace, question]. Both arms reuse identical trace text; the question remains last. Five fresh evaluation repeats are averaged per problem. These are exposed textual reasoning fields, not ordinary OTel spans or privileged internal model state. PDF, §§3–4 and Appendix C.

Numbers checked against Table 2. GraphWalks Parents exact match, percentages:

Model Initial pass Trace Append Trace as State Placement gain over Append
DeepSeek V4 Pro Preview 29.2 43.0 81.8 +38.8 points
Qwen 3.7 Max 60.8 71.0 96.4 +25.4 points
GLM-5.2 66.4 83.2 100.0 +16.8 points

The abstract's DeepSeek and GLM initial-to-final figures are correct. The more informative placement comparison is against Append, which already receives the traces and another pass. Recounting all Table 2 columns confirms 26/27 positive mean differences; GLM GraphWalks BFS F1 is the exception, 75.0 versus 75.8. This is 27 model/task/metric combinations, not 27 independent benchmarks. PDF, Table 2.

How much confidence to place in the gain. GraphWalks contains 100 BFS and 100 Parents problems; MRCR has 100 problems in each length bin. The five repeats are not five independent task sets. Appendix E clusters bootstrap resampling by problem: 20/24 GraphWalks/MRCR paired intervals lie wholly above zero, with unadjusted 95% intervals. DeepSeek Parents' placement difference is +38.8 [31.6, 46.2] points. Four intervals cross zero: DeepSeek MRCR 512K EM, Qwen BFS F1, and GLM BFS EM/F1. NUB adds only 20 questions, uses a DeepSeek judge with author manual checking, and shows Append-to-State gains of just 2, 2 and 1 points. Do not translate the 26/27 headline into 26 statistically established improvements. PDF, Tables 1-2/5 and Appendices B/E.

Why the control is useful. In DeepSeek Parents, question-first scores 53.0 EM, repeated context 50.0, answer feedback 45.4 and unrelated traces 14.2, against State's 81.8. Trace-only reaches 43.8; the original evidence still matters. These controls support testing problem-specific feedback placement beyond merely adding text. They do not isolate a unique internal mechanism. The question-first comparison also includes conservative failure scoring for nonterminal/null-termination outputs. Trace-count ablations cover one through five traces on this model and task family; they do not establish an optimal production trace budget. PDF, Table 3 and Appendices B/C/E.

Cost is material and varies by workload. Table 6 includes the source pass in its total columns. For DeepSeek MRCR 256K, State uses 97.012 million uncached-input tokens versus 67.782 million for Append, and 2.504 million output tokens versus 1.839 million. Conversely, DeepSeek GraphWalks total output falls from 97.738 to 90.482 million. These are provider-reported aggregate token counts for retained responses, not a wall-clock or invoice comparison. No uniform cost saving follows; moving context can alter cache reuse. The evaluation requests no explicit client output cap, leaving effective provider defaults unestablished. PDF, §4.1, Limitations and Appendix F.

Adjudication. Accept the paper as evidence for a placement-sensitive replay experiment. Its finite-state theorem is an adversarial, deterministic, exact, single-pass construction; the exponential bound is not measured transformer memory savings. Difficulty bands were chosen after viewing outcomes. The experiments do not cover multi-round agents, memory revocation, changing permissions or SQL execution. No independent reproduction was run here. The DeepSeek model is specifically the April 24 preview identified in Appendix C, not every later product sharing its name.

BQAA TL;DR — proposed application, not a paper result: separate captured events from the derived context supplied to a later agent call. A useful experimental record would retain source run/event IDs, source revision, model identity, serializer and truncation settings, trace count, placement, complete usage and the independently scored outcome. If only tool observations or summaries are exposed, label that as a different state interface and test it separately. Do not infer unavailable private reasoning from a successful trace capture.

For a bounded ADK/BQAA experiment, use an existing replay cohort with externally checkable answers. Freeze each context snapshot and derived trace, randomize prefix versus suffix placement, and include a fresh no-trace retry plus a question-first control. Compare one-trace and five-trace budgets separately, charge source generation as well as replay, and cluster outcomes by original problem. Include stale or contradictory trace cases to detect harmful reuse. Keep an untouched evaluation set and score complete task correctness, not the presence of plausible reasoning. This is an extension of feedback-correction and review-budget work, with no default runtime change implied.
