Academy

NEW ranks

1. Semantic Context Handoff restores completed-work evidence when later execution reopens a belief (arXiv:2611.24357)

Full PDF read: all 22 pages, including appendices A–I, Tables 1–9 and the limitations. SCH separates a compact mutable semantic state from an append-only action–observation archive. Facts, hypotheses and work items retain support/lineage handles; a deterministic controller applies sparse state deltas and, when fresh failure or a model delta reopens completed work, replays the associated historical evidence without another retrieval-model call (§§3.1–3.3, D.1–D.6).

The controlled three-run, 150-task SWE-bench study holds state machinery, lifecycle, interface and evidence budget fixed. Revision-aware recovery reaches 86.89 ± 1.39% Pass@1, versus 80.00 ± 1.33% for active-state-only provenance, at 208.6k versus 209.8k tokens/task; paired SCH-only/active-only splits are 15–4, 14–4 and 14–4 with exact McNemar p = 0.0192/0.0309/0.0309 (Table 1, §4.1). Against PACT, the complete system uses 43.3% fewer tokens and 40.8% less wall time, but its 3.11-point mean accuracy advantage is descriptive, not established (Run 1 McNemar p = 0.359; Table 2, §4.2). Recovered evidence averages 18.48 steps old, with 65.9% of occurrences more than ten steps old (§4.4, Table 8). Breadth settings are single-run, MAGE is paper-guided, pending evidence is uncapped, and provenance guarantees addressability—not semantic entailment (§6, D.6, G).

2. Deployment lessons show that the right self-distilled-memory dose depends on the model (arXiv:2611.26361)

Full PDF read: all 8 pages, including the production deployment section, appendix figures and Tables 1–6. The open-source pipeline mines one to three lessons per trajectory, consolidates them into support-preserving guidelines and delivers either all guidelines or a selected subset; it is deployed in IBM's CUGA and watsonx Orchestrate. The important result is not “more memory helps,” but a dose-by-capability interaction with explicit accounting.

On AppWorld test_normal, DeepSeek-V3.2 moves from 79.8% to 89.3% TGC (+9.5 points) and 64.3% to 80.4% SGC (+16.1) with all 191 guidelines; gpt-oss-120b reaches 51.2% with all 199 but 55.4% with about 29 selected guidelines (mean of two runs), at near-baseline token cost (Figure 1, Table 2). The full 191-guideline set costs 78% more tokens/task, while a 47-guideline set gives +5.9 TGC for +27% tokens. Repeated identical DeepSeek runs flip roughly 32 of 168 tasks, and the authors treat differences below about five tasks as noise (Insight 5). A cross-method headline gap mostly disappears when each system is compared with its own scaffold baseline; the same work reports lost provenance during consolidation, support counting recurrence rather than correctness, and a silent write-path bug that left memory empty (Insights 3, 4, 6 and 7; Table 3). Product CUGA gains with GPT-4.1 remain below that noise floor, while the stronger-model GLM arm improves with the full set at 36% more tokens (Tables 4–6).

3. LMLineage makes sentence-level provenance an out-of-band sidecar, but its compaction trigger is not ready for unattended use (arXiv:2611.22511)

Full PDF read: all 12 pages, including the annotation/calibration appendices, Tables 1–4 and limitations. LMLineage observes session events asynchronously and maps each output sentence to its best supporting input window, propagating source/confidence triplets without white-box access or an extra model inference. A fishbone view exposes turns, compactions and memory promotions with their source spans (§§3–4).

Greedy-window attribution beats line matching on fine source accuracy for all three generators (0.794/0.723/0.657 versus 0.413/0.508/0.571) and is much faster (12.3–14.8 s versus 205.9–354.7 s) in Table 1. Controlled multi-session replay stays near 1.15 s/turn through 40 turns (Table 2), but the live CPU-only worker has an 8.7 s median, reaching 168 s for 70 sentences across 41 accumulated documents; the 8 s compaction-readiness gate therefore often becomes a no-op on large contexts (§5.4). Most importantly, concept-drift micro-compaction has 0.30 recall and 0.00 false-positive rate over ten synthetic six-turn sessions, because the active document often loses attribution to the user prompt (Table 3). Fine-confidence ECE is about 0.45, versus 0.16–0.18 for coarse input attribution (Table 4). The gold set is only 71 Chinese sentences with LLM-assisted annotation, and token-savings/task-retention A/B evaluation remains future work (§§5.6, 6).

Six-week EV

  • Revision-replay shadow (high EV, 2–5 weeks). Add stable evidence ids and support/lineage links to compact task state; on verification failure or reopened work, replay completed-work evidence under a fixed budget. Run an active-state-only control and report paired task outcomes, evidence age, replay-cap hits, tokens and wall time rather than relying on a summary-quality proxy.
  • Memory-dose and provenance gate (high EV, 2–6 weeks). For each model, compare no memory, a high-support core, retrieval and the full guideline set on one fixed scaffold. Repeat runs to measure outcome flips, report tokens alongside completion, conserve source/support fields through consolidation, add correctness/recency signals, and assert store growth and minimum model-call counts so a silent empty-memory run cannot look like a negative result.
  • Lineage sidecar before compaction control (medium-high EV, 3–6 weeks). Shadow sentence-to-input-span attribution on a multilingual, independently annotated trace sample. Report coarse and fine accuracy separately, calibration, source confusion, p50/p95 latency and readiness-gate misses; permit only conservative cleanup recommendations until drift recall and task-retention A/B results justify automation.

TL;DRs for BQAA

  • SCH: preserve canonical execution evidence outside compact state and test revision-triggered replay; the controlled gain comes from completed-work recovery, while the complete-system accuracy edge over PACT is not statistically established.
  • Self-distilled memory: tune dose per model, preserve provenance and compare against your own scaffold baseline with repeated runs; a few tasks of apparent improvement can be noise, and a plausible log can conceal an empty memory store.
  • LMLineage: out-of-band sentence lineage is useful for incident drill-down, but 0.30 drift recall, weak fine-confidence calibration and CPU tail latency rule out unattended micro-compaction for now.
