Progress — openai-node v7.28.0: agent-session webhook event interfaces and a 12h cache-write token field on org usage

Parent: openai-sdk-python-3-23-0-node-7-27-0-agent-session-traces-otlp-json Primary: https://github.com/openai/openai-node/releases/tag/v7.28.0 — GitHub release 2026-10-04 18:22:13Z, prerelease=false. npm openai@7.28.0 uploaded 18:31:37Z and is now latest (was 7.27.0). Single feature commit, PR #2858 (merged Oct 2 05:55Z).

Why Progress and not NEW. A stable minor, but every change extends the session-events / usage-telemetry surface the Fri 0634 card already tracks (openai-sdk-python-3-23-0-node-7-27-0-...). PyPI openai had no in-window upload — this is Node-only this window.

What ships (release notes + PR #2858 body):

  • Agent session webhook interfaces. Typed webhook payloads for agent session lifecycle events: created, in_progress, idle, failed, action_required. This is the first typed surface for session lifecycle (not just session traces) in the OpenAI SDKs — the events an analytics pipeline would consume to reconstruct session state transitions without polling.
  • input_cache_write_12h_tokens on organization usage results. A new cost-analytics field exposing 12-hour cache-write token counts at the org usage endpoint. Cache-aware cost accounting gains another dimension beyond the existing cached-read fields.
  • Custom voice creation (audio.voices.create — uploaded sample with consent, or text prompt; prompt-created voices documented as Live-only). Not analytics-relevant; noted for completeness.
  • Beta service_tier cleanup: ultrafast removed from the beta agent and session service_tier unions — a breaking type-level change for anyone pinning ultrafast on those beta surfaces.
  • Docs: image-variations retirement and model deprecations documented.

BQAA read. Two concrete ingestion notes: (1) if you consume OpenAI org-usage exports, expect a new input_cache_write_12h_tokens key in usage rows — schema mappers should tolerate-and-capture it; (2) agent-session lifecycle is now a typed webhook event set (created/in_progress/idle/failed/action_required) — the natural join key against session traces for "what state was the session in when this span fired".
