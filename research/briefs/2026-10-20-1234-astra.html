Industry

NEW 1 — OpenAI: selectable 12-hour prompt caching changes the cost ledger

Stable, October 20. The API changelog announces selectable 12-hour prompt caching. The official guide documents prompt_cache_options.ttl: "12h", a 30-minute default, and per-breakpoint overrides. A 12-hour cache write costs 2.5× the ordinary input-token rate in total. Extending a still-valid 30-minute prefix to 12 hours incurs a new write without credit for the earlier write; existing 12-hour coverage remains a read.

Usage separates cache_write_tokens_details.ttl_30m_tokens and ttl_12h_tokens; cached_tokens excludes cache writes and upgrades. The new product capability is selecting extended cache coverage, not the first appearance of a 12-hour field: an older SDK card already mentions an organization-usage counter.

BQAA implication: test mixed-TTL prompts and coverage upgrades against invoices. Store the pricing version and TTL partition with each usage record; an undifferentiated input/cache-hit total can conceal the write premium. Model expected reuse before choosing longer coverage.

Clock evidence: primary changelog dated October 20; a public discussion linking the OpenAIDevs announcement was created at 18:03:12Z / 11:03 PT, corroborating availability before cutoff. Technical claims come from the official docs. Direct X retrieval failed; see Unconfirmed.

NEW 2 — Amazon Bedrock: Claude structured outputs GA across runtime and mantle

Stable, October 20, 14:00Z / 07:00 PT announcement. AWS announces structured outputs for Claude on Bedrock. NEW 3 — StopLoss: Teaching Agents to Predict Failure and Stop Early — arXiv:2610.25525

Full PDF read: all 19 pages, including methods, results, limitations, references and Appendices A–D; whole-file pdftotext -layout extraction and complete reading. Submitted October 18; prior-window announcement; not previously carded.

The monitor learns from terminal outcomes and periodically scores recent action/observation windows. Table 1 reports replay results for the primary Qwen2.5-7B ensemble:

Executor / benchmarkCost per retained solve change, including monitorOriginal successes retained
GPT-5.6 Luna / SWE-bench Pro−24.2%72.2%
Claude Sonnet 4.6 / SWE-bench Pro−30.6%91.6%
GPT-5.6 Luna / SWE-bench Verified−4.5%99.0%
Claude Sonnet 4.6 / SWE-bench Verified+0.2%100.0%

The nominal 5% calibration false-kill target does not transfer uniformly. §5.3, Eq. 2 makes savings conditional on avoided executor cost exceeding monitoring overhead plus the lost-success fraction. Monitor cost uses a GPU-time price proxy, not an online deployment invoice (§4.3; Appendix C.2). Frozen pricing, replay, narrow repositories and distribution shift limit portability.

BQAA interpretation: benchmark an intervention against the original success population. Report retained successes and false kills next to cost per solve, with confidence intervals and actual serving overhead. The Pro result that looks cheaper also discards many successes; that is a product tradeoff, not free efficiency. Start with shadow decisions and a held-out workload. Do not import the paper’s threshold or its GPU proxy as a production guarantee.

NEW 4 — Don't Judge an Agent by Its Messages: Private-State Leakage under Passive Monitoring of Agent Communication — arXiv:2610.25032

Full PDF read: all 23 pages, including formal proofs, experimental details, limitations, references and Appendices A–B. Submitted October 18; prior-window announcement; not previously carded.

Theorem 4.2 / Corollary 4.3 and Table 1 show that the same observable task/message/action law can coexist with different private-state leakage. Communication alone therefore need not identify leakage.

The experiments distinguish two arms. In the selection attack, private-bit recovery reaches 100%, but a selection-aware detector reaches AUC 0.972 across 16 independent messages (§6; Table 2). The law-preserving resampling arm reports 97.72% recovery and detector AUC 0.540, with a wide [0.450, 0.633] interval (Table 4). These are not evidence that every attack defeats detection. The empirical setting uses one small model and a synthetic routing task; the 16-message collections are not adaptive agent conversations. A trusted canonical task interface changes the audit assumptions (§5.3, Proposition 5.3).

BQAA interpretation: a complete-looking trace is evidence of observed behavior, not a certificate about unobserved private-state coupling. Name the property an evaluator actually checks. Where stronger assurance is required, collect trusted provenance and enforce restricted interfaces; do not respond by indiscriminately copying private state or secrets into telemetry. A privacy-certification claim needs assumptions and controls beyond a clean message score.
