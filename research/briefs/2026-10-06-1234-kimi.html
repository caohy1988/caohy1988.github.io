NEW — 2610.06514 — ANT: a multi-granularity network-traffic dataset and benchmark for agent behavior auditing — 3,114 episodes / 276,417 flows; all 13 baselines top 0.900 risk-ID accuracy yet 7 have malicious recall <0.500; four score 0.000 on malicious code generation and sandbox evasion — content-level misuse leaves almost no traffic signature

Full PDF read (dataset construction §3 with Table 1 and Fig 2, benchmark §4.1–4.4 with Tables 2–3 and Figs 5–10, limitations §5). Li, Gao, Liu, Wang, Li (RUC), Fu, Xu — Tsinghua / Zhongguancun Lab / RUC / NTU Singapore. v1 5 Oct 2026 (cs.AI).

The question: what can an outside network watcher — enterprise gateway, ISP, auditor — recover about what an agent is doing, without decrypting content? ANT pairs automated tcpdump PCAP collection with synchronized agent session logs across 5 agent configurations (Claude Code + MiMo/Sonnet/DeepSeek-domestic/DeepSeek-overseas; Codex + Qwen) on 20 tasks in 5 scenarios (Computational Artifact Engineering, General Knowledge QA, Scientific Evidence Assessment, Interactive Application Operation, Cybersecurity Misuse from PurpleLlama + OWASP Juice Shop), annotates behavior primitives from the aligned logs (LLM-annotated, clustered into 47 macro groups), and benchmarks 13 encrypted-traffic/website-fingerprinting baselines on three objectives (§3, §4.1).

Measurements: the dataset itself (§3, Table 1) — 3,114 episodes, 659 task instances, 276,417 bidirectional flows, 40,049 primitive segments, 104.07 GB, collection cost $2,176.50. Risk identification (§4.2, Table 3, Fig 5): every baseline exceeds 0.900 accuracy, but 7 of 13 have malicious-class recall below 0.500 (AWF 0.150, FlowLens 0.200; best: TikTok acc 0.981 / F1 0.905 / recall 0.950), and YaTC, NetMamba, TFusion and TrafficFormer score 0.000 recall on malicious code generation and sandbox evasion while ~1.000 on web penetration — the misuse that matters most is the least traffic-visible. Scenario recognition (§4.3): 0.431–0.727 accuracy (NetMamba best); Evidence Assessment ↔ Knowledge QA mutually confuse at 35.1%/22.8% (Fig 7); model-call traffic is the dominant signal — keeping only model-call traffic improves average accuracy +5.56pp, excluding it costs −4.31pp (Fig 8), and clearing one task-representative primitive segment costs −6.95pp vs −3.77pp for a random one (Fig 9). Primitive classification (§4.4, Fig 10): 0.355–0.462 accuracy; the 10 most frequent groups hold 72.44% of segments and produce 91.34–96.09% of all correct predictions — long-tail behaviors are effectively invisible.

Stated limits (§5): budget-limited coverage of agent apps/configs; AI-assisted annotation (mitigated by iterative review + 2,000-sample spot check); controlled environments may shift timing vs real deployments; dual-use acknowledged.

Why it ranks. The calibrated map of agent systems' external observability surface: it quantifies which agent behaviors are recoverable from traffic metadata alone (web penetration, search-vs-fetch, scenario class) and which are not (malicious intent in code generation) — grounding both network-level agent auditing and the privacy side of agent telemetry (your gateway can see more about agent tasks than most deployment docs assume, and less about agent intent). The direct complement to AgentSpy (carded at 0034), which observes from the syscall layer inside the VM: ANT is the outside-the-network-layer twin, and its 0.000-recall result is the quantitative argument that content-blind auditing cannot substitute for trace-level evidence.

NEW — 2610.04794 — Knowing the Store: what a memory backend must write down before an agent can read it — under real-store metadata, frontier readers collapse to a cosine name lookup; FR-Bank over-marks stale ~58×; Mem0 exposes updated_at on 12.7% of entries; A-MEM resolves 0 of 23,186 links; lifecycle-aware fetch raises forbidding-record reach 0.52→0.82

Full PDF read (task and counterfactual design §4 with Table 1, controls §5 with Table 2, backend census §6 with Table 3, retrieval §7 with Table 4, replication §8, limitations §9). Mullick & Tüzün, Bilkent University. v1 3 Oct 2026 (cs.AI; code/data: github.com/ansh348/knowing-the-store).

The problem: an agent with long-term memory answers from records it should no longer use (a cancelled plan — a "forbidding record"). What must the store expose so a reader can judge, before retrieval, coverage (feeling-of-knowing) and negative obligation (NOK)? Readers see only a value-free lifecycle summary (record counts by state — active/superseded/retracted/expired — plus attribute names); the design is counterfactual — 148 questions × 3 store versions differing in exactly one attribute (444 items), so wording cannot leak labels. Readers: GPT-4.1 mini, Haiku 4.5, GPT-5.6 Luna, GPT-5.6 Sol, Opus 5 (+ Kimi K3 cross-vendor replication) against no-model baselines (cosine name lookup, count readers).

Measurements: (Table 1) on short ground-truth lists, no model reliably beats the name lookup (lookup 0.77 on the superseded-named summary vs Luna 0.84 / Sol 0.85 / Opus 0.84 — the three strong readers equivalent within 0.05; question-only = 0.50). (Table 2 controls) padding to 60 names drops the lookup 0.92→0.74 while Luna/Sol lose only 0.06–0.07 and lead it by 0.13–0.14; moving the obligation's count to a sibling store drops Luna/Sol/Opus 0.28–0.33 (they read counts; mini/Haiku don't move); and under FR-Bank's own metadata, mini/Haiku/lookup fall from 0.73/0.82/0.75 to 0.60/0.71/0.59 — real-store metadata erases the readers' edge. (§5.3) told the intent rule explicitly, Luna/Sol/Opus score 0.88–0.99 vs mini 0.48 / Haiku 0.55; untold, only Opus (0.90) applies it. (Backend census, §6, Table 3:) FR-Bank marks 5,968 of 18,936 entries stale vs ~102 in the reference (~58× over-mark) and retains an active obsolete assertion after 72% of supersession events; Mem0 1.0.5 exposes updated_at on only 12.7% of 10,074 entries (UPDATE overwrites; silently lossy ingest); A-MEM 0.0.1: all 23,186 link references across 11,319 notes resolve to 0 note ids; Graphiti invalidates 13 of 34 expressible obligations and cannot express retraction in its mapping. (§7, Table 4) top-5 cosine retrieval puts only 0.52 of forbidding records in view; a name-keyed lifecycle fetch raises reach to 0.82 — and the always-on fetch matches the model-gated one at matched budget; newest-per-attribute reaches 0 of 26 retraction obligations (the cancellation is never the newest record of its attribute). (§8) the summary's gains replicate 0.15–0.45 across vendors (Kimi included); on the full 661-question obligation set, no completed model reliably beats the lookup.

Stated limits (§9): all stores synthetic (40 personas), transfer untested; read-side only, no write-path intervention; small retraction/expiry groups (30 pairs); matched metric post hoc; whether a better judgment changes the final answer left to later work.

Why it ranks. The write-path counterpart to MemLeak (carded at 0034): MemLeak showed pooled stores leak across users on the read path; this shows today's stores don't even record the lifecycle state a correct read path would need — and that when they don't, frontier-model readers are no better than a cosine lookup. The actionable import is a concrete telemetry spec for memory backends (keep non-active records reachable with lifecycle tags; maintain names for superseded/retracted/expired content; never let UPDATE silently overwrite) plus a counterfactual method for scoring pre-retrieval judgment separately from answer accuracy — directly ingestible as memory-store health metrics, with the "always-on lifecycle fetch matches the model-gated one" result a rare free-lunch finding.

The gap: proactive agents turn idle compute into assistance before being asked, but even correct work can impose review costs and erode trust — and existing evaluations collapse task success, timing and trust into one score. The paper defines 3T objectives — Task Capability (TC), Temporal Allocation (TA), Trust (TR) — over a 5-dimension design space, and builds PROACTIVITY-GYM: 10 multi-day scenarios (7–10 simulated days) × 3 personas with stateful tools, a simulated clock, a persona-conditioned user simulator and NOOP cases; 23 model×harness configs (9 models × OpenClaw / Claude Code / Codex harnesses), 3 runs per scenario-persona; plus a 30-participant human study on 14 scenarios.

Measurements: (§5.2, Fig 6a, Table 7) Claude Opus 5 gets the best TC (avg 65.1) but only 51.7% TA and 52.4% TR-D; every other model is below 20% TA — agents specifically fail to defer competing work. Harness as a measured variable (Table 7): Opus 5 on Claude Code scores TC 62.74 / TA 41.11 / TR-D 54.27 / TR-J 4.35 vs on OpenClaw TC 67.38 / TA 62.22 / TR-D 50.49 / TR-J 4.15 — switching harness moves temporal allocation by +21.1pp; open-weight models switching Claude Code→OpenClaw lose TC 3.6 points on average (range −11.1 Gemma 4 12B to +0.5 Qwen 3.5 27B, Fig 6b). Judges conflate capability and trust (Fig 6c): TC correlates weakly with TA (r=0.31) and TR-D (r=0.34) but strongly with TR-J (r=0.70) — Opus 5 scores 4.72/4.60 on judge-rated understandability/competence despite 52.4% TR-D — with cross-judge agreement .993/.950/.980 (Table 6), so the conflation is systematic, not noise. (App F.2) GPT 5.6-Sol reasoning none→xhigh raises TC 49.96→58.93 and TA 10%→17.2% while trust stays flat. (Human study, §5.3, Fig 7:) correct work preferred in 92.2% of comparisons; with content held constant, intervention-aligned agents chosen in 88.3%; acceptance of correct assistance jumps from 26.7% when it competes with ongoing work to 97.8% for sleep-time assistance even when output needs correction; trust is asymmetric — one aligned→misaligned transition costs −1.86 (1–5) vs +1.27 for the reverse, and after an aligned-misaligned-aligned sequence trust recovers only to 3.43 vs an initial 4.43 even though the final intervention itself rates 4.71.

Stated limits (§6): initial testbed with simplified resource constraints and user models; simulated users; longer-term real-world evaluation future work.

Why it ranks. Two results this brief's thread needed: (1) more controlled evidence that the harness is a first-class experimental variable — a >20pp swing on a measured behavior from swapping Claude Code/Codex/OpenClaw on the same model, landing one week after "What Does a Harness Buy?" (carded at 0034) showed the cost side of the same variable; any agent benchmark that doesn't declare its harness is confounded. (2) A concrete warning for automated agent-quality scoring: LLM judges systematically mis-score trust by tracking capability while humans punish a single misaligned intervention sharply and durably — judge-based trust metrics will over-credit capable-but-clumsy agents. For BQAA-class analytics, TA/TR-D are measurable-from-trace quantities (when did it act vs what was running; intervention depth vs user state) — a template for proactive-behavior telemetry before the proactive-agent wave ships.
