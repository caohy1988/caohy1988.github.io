Takeaways

  • Version split: Apps protocol is 2026-01-26; base MCP revisions (2025-11-25, 2026-07-28) are a separate layer. Only VS Code source pins the Apps value; no released-build UI response is captured in this evidence set. For Antigravity Desktop, base date literals through 2025-11-25 were found; no negotiated maximum was established.
  • Capability counting: the pinned interface has nine named nonexperimental top-level feature fields plus experimental; earlier "10 capabilities" checklists counted sandbox.permissions and sandbox.csp separately and omitted experimental. Neither count measures runtime conformance.
  • CLI hosts (Claude Code, OpenAI Codex CLI, Antigravity CLI) stay unk: Apps advertisement, mounting, and UI negotiation remain unverified in this evidence set; the linked vendor guides cover standard MCP only, and no linked inspection receipt for any CLI binary or flag state is retained.
  • Desktop split: OpenAI Codex Desktop's inspected bundle contains Apps-related sandbox, schema, internal Desktop→app-server initialization, and gate code; its server-facing advertisement and UI behavior were not captured, the gate's in-code default is false, the one historical report leaves the "Codex" surface unstated, and the vendor page is silent. Antigravity Desktop's inspected 2.2.1 artifacts yield no matches for the named Apps strings; its sidecar/window code and later auxiliary-pane release notes do not establish SEP-1865 support, and generative_ui is a CLI-directory skill whose Desktop applicability is unverified. Vendor docs, sidecars page, and changelog through 2.13.0 (Sep 9, 2026) never mention Apps. Antigravity Desktop remains unk; the September 2.13.0 release was not inspected, so the inspected bundle lags the current release by eleven minor versions.
  • App-only visibility (spec) is unverified on every host; needs an instrumented probe.
  • Fallback: VS Code alone has a documented user switch; its off and error paths are pinned code facts, not runs. Codex Desktop has inspected conditional fallback/error branches, no Apps-specific user switch identified in reviewed sources, and no run. Ship readable text and optional images as standard content (REC).
